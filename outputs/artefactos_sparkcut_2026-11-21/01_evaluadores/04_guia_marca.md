# Guía de marca SparkCut

**Personalidad:** clara, práctica y orientada a creadores.  
**Colores sugeridos:** azul profundo `#172554`, cian `#06B6D4`, fondo claro `#F8FAFC`.  
**Tipografía:** Inter para interfaz y títulos.  
**Uso del nombre:** siempre `SparkCut`, con C mayúscula; no usar “viral predictor”.

El logotipo vectorial puede elaborarse en SVG a partir del nombre y la paleta anterior; este documento deja una guía reproducible para la entrega.
