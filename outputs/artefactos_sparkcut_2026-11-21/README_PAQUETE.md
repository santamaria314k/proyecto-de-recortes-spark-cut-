# Paquete de artefactos SparkCut

Esta carpeta contiene copias y artefactos preparados para subir a Google Drive. El proyecto original no fue modificado por la preparación de este paquete.

## Cómo usarlo

1. Sube la carpeta completa a Drive conservando sus subcarpetas.
2. Usa `PLAN_DE_TRABAJO_SparkCut_completado.xlsx` para consultar la ruta local de cada artefacto.
3. Si tu tabla exige un enlace, copia el enlace de Drive de la carpeta o del archivo correspondiente en la columna **ARTEFACTOS**.

## Nota de honestidad académica

Los elementos marcados como “plantilla” o “pendiente de ejecución” deben completarse con videos, capturas o resultados reales antes de presentarlos como evidencia ejecutada.
